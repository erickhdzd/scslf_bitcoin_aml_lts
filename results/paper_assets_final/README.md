# Bitcoin AML publication assets

This directory contains the publication-ready tables, figures, captions, manuscript fragments, reproducibility metadata, and verification reports generated by `generate_paper_assets.py`.

## Directory structure

- `paper/`: main-manuscript tables and LaTeX assets.
- `supplementary/`: supplementary tables and LaTeX assets.
- `figures/`: publication figures in PNG and PDF formats.
- `captions/`: editorial captions for tables and figures.
- `manuscript/`: automatically generated Results-section drafts.
- `reproducibility/`: environment, configuration, input-file hashes, and reproducibility metadata.
- `delivery/`: deterministic ZIP package and verification files.

## Main manuscript integration

The main manuscript assets can be included from the package root with:

```latex
\input{paper/integration/ManuscriptAssets.tex}
```

## Supplementary integration

The supplementary assets can be included from the package root with:

```latex
\input{supplementary/integration/SupplementaryAssets.tex}
```

The generated LaTeX assets require:

```latex
\usepackage{booktabs}
\usepackage{graphicx}
\usepackage{subcaption}
\usepackage{tabularx}
```

## Validation

`PUBLICATION_CHECK.txt` reports the structural, numerical, editorial, reproducibility, and LaTeX-dependency checks.

`delivery/PACKAGE_CHECK.txt` reports the integrity verification of the deterministic ZIP archive.

## Hash verification

The SHA-256 hash of every packaged asset is listed in `delivery/PACKAGE_CONTENTS.sha256`.

The SHA-256 hash of the ZIP archive is stored in `delivery/ARCHIVE_SHA256.txt`.

Example verification command:

```bash
sha256sum -c results/paper_assets_final/delivery/PACKAGE_CONTENTS.sha256
```

## Reproducible generation

Build timestamps are controlled with the `SOURCE_DATE_EPOCH` environment variable.

Example:

```bash
export SOURCE_DATE_EPOCH=1785366000
python src/generate_paper_assets.py
```

Two executions using the same inputs, software environment, configuration, and SOURCE_DATE_EPOCH should produce bit-for-bit identical ZIP archives.
